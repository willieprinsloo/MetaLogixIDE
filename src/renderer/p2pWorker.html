MetaLogix IDE — P2P worker

This window is a background runtime for the IDE's peer-to-peer features (pairing, fleet relay, remote shells). It has no UI of its own — all state is surfaced in the main MetaLogix IDE window.

You can safely close this window if you opened it by accident; it will be respawned automatically when the main app needs it.

Settings → P2P / Fleet in the main window lets you pair, unpair, and inspect peers.
